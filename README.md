# Вайбкодинг — учебный проект

Сайт для проектной работы ученика Гимназии «Исток» **Панкова Владислава Александровича**. Код создан с помощью ИИ. Тема: возможности и ограничения искусственного интеллекта в программировании.

## Состав
- `index.html` — главная страница.
- `about.html` — проблема, цель, задачи и методика.
- `articles.html` — 10 материалов с аннотациями и фильтром.
- `glossary.html` — 36 терминов с поиском.
- `information.html` — подробная теория, запросы, код, проверки и безопасность.
- `assets/styles.css`, `assets/main.js` — оформление и интерактивность.
- `assets/images/author.jpg` — светлая заглушка фотографии 3:4 (900×1200).
- `assets/images/circuit-bg.webp` — фон из презентации.
- `assets/images/istok-logo.png` — эмблема из материалов проекта.
- `.nojekyll` — публикация без обработки Jekyll.

## Публикация через GitHub Pages
1. **Распакуйте ZIP. GitHub не распаковывает загруженный архив автоматически.**
2. Создайте публичный репозиторий, например `vibecoding-project`.
3. Загрузите содержимое папки `istok-site` в корень репозитория (Add file → Upload files). `index.html` должен лежать в корне, а не во вложенной папке. Сохраните структуру `assets`. При загрузке через браузер можно перетащить файлы и папку `assets` вместе. Скрытый файл `.nojekyll` при необходимости создайте через Add file → Create new file.
4. Сделайте коммит.
5. Откройте Settings → Pages → Build and deployment.
6. Source: **Deploy from a branch**; Branch: **main**; Folder: **/ (root)** → Save. Если ваша ветка называется иначе, выберите её.
7. Дождитесь завершения публикации. GitHub покажет ссылку в Pages; проектный адрес обычно: `https://USERNAME.github.io/vibecoding-project/`.
8. Откройте ссылку и проверьте все страницы. При ошибке 404 проверьте положение `index.html`, ветку и статус публикации.

Не загружайте сам ZIP вместо файлов. Для создания готового репозитория без сборки дополнительные Actions и пакеты не нужны. Для приватных репозиториев доступность Pages зависит от тарифа; для учебного проекта проще публичный репозиторий.

## Как заменить фотографию
1. Подготовьте портрет **3:4**, например 900×1200 пикселей.
2. Экспортируйте его как настоящий JPEG с именем **author.jpg**. Простое переименование PNG в JPG не конвертирует изображение.
3. Замените `assets/images/author.jpg` и сделайте коммит. Путь и имя должны совпасть точно; регистр имеет значение.
4. В `index.html` замените alt `Светлая заглушка для будущей фотографии автора проекта` на `Панков Владислав Александрович — автор проекта`.
5. Обновите страницу после публикации. Если видна прежняя заливка, обновите без кеша (Ctrl+Shift+R).

Рамка использует `aspect-ratio: 3 / 4` и `object-fit: cover`, поэтому форма сохраняется. Если лицо обрезается, настройте `object-position` у `.portrait-frame img` в CSS. Публикуйте фото только с необходимым согласием.

## Локальный просмотр
Просто откройте `index.html` в браузере: основные страницы, меню, поиск и фильтры работают без сборки, внешних библиотек и интернета. Для более реалистичного тестирования запустите из папки проекта `python3 -m http.server 8000` и откройте `http://localhost:8000`. Копирование использует Clipboard API, если доступно; иначе применяется запасной способ с выделением текста.

## Как редактировать
Тексты находятся непосредственно в HTML и доступны без JavaScript. Цвета задаются переменными в начале `assets/styles.css`. Разметка шапки, меню и подвала повторяется на каждой странице; при изменении навигации обновите все пять файлов. Статьи содержат ссылки на первоисточники; некоторые материалы на английском. Периодически проверяйте актуальность ссылок.

## Проверка после изменений
- Все пять страниц и внутренние переходы.
- Кнопка меню, Escape, клик по фону, Tab, возврат фокуса.
- Поиск: русский/английский, разный регистр, пустое поле, неизвестное слово, сброс.
- Фильтры статей и число найденных материалов.
- Копирование запросов и блока кода.
- Телефонная ширина около 390 px, увеличение текста, горизонтальный скролл.
- Режим уменьшенного движения; доступность текста без JavaScript.
- Консоль браузера и загрузка изображений.

## Ограничения и права
Сайт не содержит API-ключей, встроенной ИИ-модели, регистрации, аналитики или базы данных. Поиск выполняется только внутри страницы. Внешние статьи открываются в новой вкладке, и на сторонних сайтах действуют их собственные правила. Проверки одного статического сайта не доказывают надёжность ИИ для любых программ.

Эмблема и фон взяты из предоставленных материалов презентации. Перед публичной публикацией убедитесь, что их использование разрешено. Сторонние статьи не скопированы: приведены только ссылки и краткие авторские аннотации. Универсальная лицензия на сторонние изображения и символику не предоставляется этим архивом.
