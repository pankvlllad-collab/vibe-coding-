# Вайбкодинг — учебный проект

Сайт для проектной работы ученика Гимназии «Исток» **Панкова Владислава Александровича**. Код создан с помощью ИИ. Тема: возможности и ограничения искусственного интеллекта в программировании.

## Состав
- `index.html` — главная страница.
- `about.html` — проблема, цель, задачи и методика.
- `articles.html` — 10 материалов с аннотациями и фильтром.
- `glossary.html` — 36 терминов с поиском.
- `information.html` — подробная теория, запросы, код, проверки и безопасность.
- `assets/styles.css`, `assets/main.js` — оформление и интерактивность.
- `assets/images/author.jpg` — светлая заглушка фотографии 3:4 (900×1200).
- `assets/images/circuit-bg.webp` — фон из презентации.
- `assets/images/istok-logo.png` — эмблема из материалов проекта.
