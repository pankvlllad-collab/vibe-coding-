Гимназия «Исток» / учебный проект

02 / Исследование и практика

Полезные статьи

10 материалов для осмысленной работы с ИИ: понятие, запросы, проверка, безопасность и практика.

Маршрут чтения

Начните с материалов 01–02, затем изучите запросы и проверки. Перед публикацией прочитайте о безопасности и GitHub Pages.

Материалы преимущественно на английском. Названия и аннотации на сайте — на русском.

Показано материалов: 10

01

Понятие / Andrej Karpathy · цитата у Simon Willison

Первоисточник термина «vibe coding» ↗

Описание исходного подхода: говорить модели, что изменить, запускать результат и почти не читать код. Помогает понять происхождение термина и контекст небольших экспериментальных проектов.

Для введения и определения термина.

Читать оригинал · simonwillison.net ↗ (в новой вкладке)
02

Понятие / Simon Willison

Не вся разработка с ИИ — вайбкодинг ↗

Статья объясняет различие между слепым принятием сгенерированного кода и ответственным использованием ИИ. Отдельно рассматривает риски секретов, приватности и платных API.

Для раздела об ограничениях и роли человека.

Читать оригинал · simonwillison.net ↗ (в новой вкладке)

Запросы / OpenAI Help Center

Как давать ИИ ясные инструкции ↗

Рекомендации по структуре запроса: конкретная задача, разделение инструкции и контекста, явное описание желаемого формата. Принципы можно применять и к учебным запросам на генерацию кода.

Для составления и улучшения промптов.

Запросы / Anthropic / Claude Code Docs

Практики работы с Claude Code ↗

Практическое руководство по работе с агентом: задавать конкретный контекст, учитывать ограниченность контекстного окна и выстраивать проверяемый процесс. Полезно даже при выборе другого ИИ-инструмента.

Для планирования итераций и управления контекстом.
