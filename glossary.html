Гимназия «Исток» / учебный проект

03 / Исследование и практика

Глоссарий
определений

Термины, которые помогают понимать ИИ, читать код и осознанно проверять результат.

Найдено терминов: 36

Vibe coding

Вайбкодинг

Создание программ через запросы к ИИ и последовательную оценку полученного результата. В исходном, узком смысле — с минимальным чтением и пониманием кода. В широком употреблении термин иногда обозначает почти любую разработку с ИИ.

Например: описать игру, запустить сгенерированный вариант и попросить изменить поведение.

AI-assisted development

Разработка с ИИ-помощником

Подход, при котором ИИ помогает писать и объяснять код, но человек читает изменения, понимает решение и проверяет его. Не тождественен вайбкодингу в узком смысле.

Например: принять предложенную функцию после чтения и тестов.

Generative AI

Генеративный ИИ

Системы, создающие текст, изображения, код и другие данные на основе закономерностей, освоенных при обучении.

Ответ может выглядеть убедительно и при этом быть ошибочным.

LLM

Большая языковая модель

Модель, обученная на больших объёмах данных и способная генерировать последовательности токенов с учётом контекста.

Может предложить код, но его работоспособность нужно проверить запуском.

Prompt

Промпт

Инструкция или запрос, передаваемый ИИ: задача, контекст, ограничения и ожидаемый результат.

«Сделай меню, которое закрывается по Escape и возвращает фокус на кнопку».

Context

Контекст

Информация, доступная модели при формировании ответа: сообщения, фрагменты кода, файлы и результаты инструментов.

Для исправления ошибки полезны её текст, соответствующий файл и шаги воспроизведения.

Context window

Контекстное окно

Ограниченный объём информации, который модель может учитывать за один раз. Обычно измеряется в токенах.

При длинной переписке часть ранних деталей может стать недоступной.

Token

Токен

Единица представления текста для модели: часть слова, слово, знак или другой фрагмент. Не равен одной букве или одному слову.

Длинные файлы и переписка расходуют больше контекстного окна.

Hallucination

Галлюцинация модели

Ответ с вымышленной или неверной информацией, представленным как достоверный факт.

Например: вызов функции библиотеки, которой на самом деле не существует.

Iteration

Итерация

Один цикл уточнения: получить вариант, проверить его и внести ограниченное изменение.

После исправления меню снова проверить остальные страницы.

AI agent

ИИ-агент

Система, которая использует модель и инструменты для выполнения последовательности действий: чтения файлов, редактирования, запуска команд.

Права на удаление файлов и публикацию нужно ограничивать.

Sandbox

Песочница

Изолированная среда, ограничивающая доступ программы или агента к остальной системе.

Проверка неизвестного кода без доступа к личным файлам.

Prototype

Прототип

Ранняя версия продукта для проверки идеи и поведения, не обязательно готовая к эксплуатации.

Работающий макет формы ещё не означает безопасное хранение данных.

MVP

Минимально жизнеспособный продукт

Версия продукта с минимальным набором функций, достаточным для проверки ключевой пользы для пользователя.

Не просто красивый макет, а доступная пользователю основная функция.

HyperText Markup Language

HTML

Язык разметки, определяющий структуру веб-страницы: заголовки, ссылки, текст, изображения.

Элемент button задаёт настоящую кнопку, а не только её внешний вид.

Cascading Style Sheets

CSS

Язык описания оформления: цвета, шрифты, расположение, адаптивность и анимации.

Медиазапрос позволяет изменить сетку на узком экране.

JS

JavaScript

Язык программирования для поведения веб-страниц и многих других задач.

Поиск по глоссарию и обработчики кнопок на этом сайте.

Document Object Model

DOM

Объектное представление документа, с которым JavaScript может работать.

Изменение textContent заменяет текст выбранного элемента.

Application Programming Interface

API

Согласованный способ взаимодействия программ или компонентов.

Приложение может запросить погоду у сервиса через его API.

API key

API-ключ

Секретный идентификатор для доступа к сервису; его раскрытие может привести к чужому использованию и расходам.

Ключ нельзя безопасно спрятать в JavaScript публичного сайта.

Frontend

Фронтенд

Часть приложения, с которой взаимодействует пользователь, обычно в браузере.

Разметка, оформление и меню этого сайта.

Backend

Бэкенд

Серверная часть приложения: обработка запросов, правила доступа и работа с данными.

У этого информационного сайта нет собственного бэкенда.

Static website

Статический сайт

Сайт, отдающий готовые файлы HTML, CSS и JavaScript без генерации страниц собственным серверным приложением.

Он всё равно может иметь анимации и поиск в браузере.

Repository

Репозиторий

Хранилище файлов проекта и, при использовании Git, истории их изменений.

Репозиторий на GitHub содержит код сайта.

Version control

Git

Система контроля версий для сохранения изменений и работы с историей проекта.

Перед экспериментом можно сохранить рабочую версию коммитом.

Commit

Коммит

Зафиксированный набор изменений в Git с идентификатором и сообщением.

«Исправить закрытие меню по Escape».

Difference

Diff

Представление разницы между версиями файлов: что добавлено и удалено.

Помогает заметить, что ИИ изменил не только нужную функцию.

Static hosting

GitHub Pages

Сервис GitHub для публикации статических сайтов из репозитория.

Не запускает произвольный Python-бэкенд как серверное приложение.

Debugging

Отладка

Поиск причины ошибки, её исправление и проверка результата.

Сначала воспроизвести ошибку, затем менять код.

Refactoring

Рефакторинг

Изменение внутренней структуры кода с сохранением его поведения.

Объединить повторяющиеся обработчики без изменения функций сайта.

Testing

Тестирование

Проверка поведения программы на заданных сценариях и входных данных.

Проверить пустой запрос, неизвестный термин и поиск на телефоне.

Regression

Регрессия

Ошибка в ранее работавшей функции, появившаяся после изменений.

После обновления анимации перестало закрываться меню.

Accessibility / a11y

Доступность

Свойство интерфейса, позволяющее пользоваться им людям с различными возможностями и средствами ввода.

Клавиатурная навигация, понятные подписи и достаточный контраст.

Responsive design

Адаптивная вёрстка

Оформление, которое подстраивается под размер экрана, сохраняя читаемость и функции.

На телефоне две колонки становятся одной.

Prompt injection

Инъекция промпта

Попытка внедрить инструкции через недоверенные данные и изменить поведение ИИ-системы.

Комментарий в чужом файле, требующий раскрыть секреты, не должен становиться командой агенту.

Dependency

Зависимость

Внешняя библиотека или пакет, используемый проектом.

Название, версия, лицензия и источник пакета должны быть проверены перед установкой.
